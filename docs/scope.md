# Startup on Fire — Phase 1 Scope

## Included

- Honest Git baseline and task audit trail.
- Single-package Vite, TypeScript, Phaser 3, Convex, Vitest, ESLint, and Prettier foundation.
- Minimal responsive canvas and compact DOM status overlay.
- Convex health connection, CI, and production build.
- Isolated World Selfie Check and ENSv2 Sepolia feasibility spikes after the scaffold checkpoint.
- Gated public GitHub repository and Vercel preview.

## Excluded

- Plaza gameplay, player movement, booths, NPC dialogue, quests, and fuel mechanics.
- Runtime art or concept-art generation.
- Final World verification, ENS booth identity, or server-authoritative voting integration.
- Foundry, The Graph, authentication, wallets for ordinary exploration, and all P1/P2 features.

## Phase 1 exit gate

The foundation is complete only when local quality commands pass, the Phaser shell reaches a configured Convex deployment, isolated sponsor spikes have truthful evidence, and a clean browser can load the public preview. Each checkpoint requires diff review and human approval before commit.
