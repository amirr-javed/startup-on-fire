# SOF-005 prompt archive — Greybox plaza and initial runtime assets

## Builder request

Start the next core-product phase and generate assets. Continue to defer World, Vercel, and other sponsor technologies until the core product is built.

## Implemented interpretation

Build the Day 2 greybox exit path: compact plaza, movement, camera, collision, three booths and founders, fountain landmark, contextual interactions, and landscape touch controls. Generate an initial original runtime batch for terrain, booths/props, Scout, and founders. Do not add dialogue quests, fire, minigame, sponsor integrations, publication, or deployment.

## Image-generation prompt

Create an original visual reference sheet for a cozy top-down 16-bit pixel-art game called Startup on Fire. Show separately spaced startup booths, a cream-stone fountain, a Scout, and three founders in the approved green/cream/wood/charcoal/ember/yellow/limited-blue palette; no purple, text, logos, HUD, crowd, or fire. Use simple geometry suitable for reinterpretation at a 16×16 tile basis and 16×32 character scale.

## Human and implementation boundary

The generated image was judged non-runtime because it included a painted background and incorrect scale. It was retained as a reference. Exact runtime PNGs were built separately with deterministic dimensions, alpha, metadata, and hashes, then loaded and inspected in Phaser.
